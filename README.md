## About PID Grabber
MK7 PID Grabber is plugin that will grab the principal ID of all the current players in the lobby if your spectating or just playing the game. 

## Features
- Logging. For when if you see a hacker but to late to report in time, you can view the logs of every lobby you've been in. But it only works in the Game because they're only encrypted to the game and can not be viewed in a text editor
- Some Optimization Features
- Spectator Feature (when in-game) It will tell you how to use it.
- And more

## How to install?
- Download the plugins from someone you got it from in discord.
- Take out SD card & plug it in to your computer. Or use [FTPD](https://github.com/mtheall/ftpd) and a **FTP Client** to put the plugin in the right folder.
- Go to **sd/luma/plugins**
- If don't have a folder with your MK7 ID, Make one with the IDs listed bellow.
   - USA: 0004000000030800
   - EUR: 0004000000030700
   - JPN: 0004000000030600
 
- Once you're done that, take out your sd card from your computer and put it back in. If you use FTPD, exit FTPD
- Make sure **Plugin Loader** is on first. To do that, Open the Rosalina Menu (L+DPADDown+Select) and scroll down to **Plugin Loader**. If its disabled, Just press A on it and it will say **"Plugin Loader: Enabled"** and then press B until your out of the menu. If its enabled, Just back out of it.
- Launch Mario Kart 7
- And press select to make sure the plugin works and you're done!!
