Grabs the Principal ID of any Mario Kart 7 player you come across.

Mainly used to report hackers on Pretendo

## How To Install

Find the Title ID of Mario Kart 7

JPN: 0004000000030600

EUR: 0004000000030700

USA: 0004000000030800

Create a folder with the ID in sd:/luma/plugins and put the plugin in there.

Before booting, make sure the plugin loader in Luma is enabled l+down+select (or any combo you have) -> Plugin Loader (Disabled) to Plugin Loader (Enabled)

Upon booting MK7, your screen should flash blue. Press SELECT to open the menu.

When joining an online match, the plugin should automatically log the Principal ID of the players you come across, as well as being able to detect spoofed PIDs

## How to switch to a different plugin (if needed)
- Launch FBI
- Go to "SD Card"
- Click on "luma"
- Click on "plugins"
- Click on your MK7 Title ID Folder
- You'll have to change the name if you have multiple plugins.
- Click on the plugin you want to change the name of
- Go to the end when your keyboard is prompted and name it "3gxoff." That way, you can keep your plugin without deleting it.

- That's it!
